# GitHub Setup & Website Card Mapping

## One repository containing six case guides

1. Extract the ZIP and open the `ba-domain-questions` folder.
2. Upload its **contents** to the repository root.
3. Keep each case folder and its local `assets` and `SOURCES.md` files intact.
4. Open each case folder on GitHub. Its README appears automatically.
5. Copy that case-folder URL into the matching **View BA Questions** link on your website.

Suggested repository name: `questions-a-ba-should-ask`.

Use the actual published URL from your repository; no GitHub username or repository URL is assumed in this pack. The files are prepared for upload and have not been published or connected to the website.

## Six separate repositories

Each case folder contains a self-contained `README.md`, local `assets/banner.svg`, and `SOURCES.md`. Upload the **contents of one case folder** to a repository root, then repeat for the others if desired. There are no required links from those case READMEs to the collection root.

The separately named README downloads are content copies for convenience. Rename a selected one to `README.md` when uploading, and use the matching case’s `assets` and `SOURCES.md` from the ZIP. Uploading the complete case folder is simpler.

## Formatting

The black-and-gold SVG banners echo the portfolio’s visual style. GitHub controls Markdown body fonts and colours; unsupported CSS is not needed. The question tables and in-page links use GitHub-compatible Markdown and HTML anchors.
